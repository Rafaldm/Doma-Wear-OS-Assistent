# Interação com Sensores de Smartphones e Wearables

Este repositório tem os dois projetos feitos para a disciplina **DGT2816**:  

1. **ListaDeTarefas** – App Android para criar e gerenciar tarefas.  
2. **DomaWearAssist** – App Wear OS para assistência a funcionários com necessidades especiais.

---

## Estrutura do Repositório

- `ListaDeTarefas/`  
  - Criar e ver tarefas  
  - Botões para adicionar ou interagir com tarefas  

- `DomaWearAssist/`  
  - Notificações e alertas via botão (validadas por log)  
  - Botão para abrir configurações de Bluetooth  
  - Testado no emulador Wear OS  
  - Áudio não reproduz por falta de TTS no emulador
